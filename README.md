# Alumable Gamification Engine

A gamification engine designed to increase student engagement
through activities, challenges, XP, levels and platform unlocks.

## Project Overview

The system allows educators and employers to define activities
and challenges. Students complete these activities to earn XP,
progress through levels and unlock platform capabilities.

## Main Features

- Activity and challenge management
- Student activity completion
- XP allocation and transaction tracking
- Level progression
- Capability unlocking
- Student progress dashboard
