# What works now
We currently have a Laravel-based XP engine with a basic web demo. It supports configurable activities, XP awards, student levels, capability unlocks, transaction history, adjustments, reversals, and APIs intended for Alumable’s existing mobile app and future educator/employer portals. The UI currently simulates progression, while the backend and local SQLite database provide the foundation for real integration later.
