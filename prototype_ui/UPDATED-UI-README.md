# Updated UI prototype

`alumable-gamification.html` is the updated HTML design supplied for the prototype.

The React frontend exposes the same design at `/prototype` and stores the browser-ready source under:

`frontend/public/prototype/alumable-gamification.html`

This keeps the supplied design available as an exact visual reference without replacing the existing API-connected React employer/educator screens.

## Run React

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL and select **UI Prototype** in the sidebar, or navigate to `/prototype`.
